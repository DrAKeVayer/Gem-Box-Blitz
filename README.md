
# Gem Box Blitz: First Demo

A puzzle game built with **Godot Engine**, blending the core box-selection mechanics of **Fruit Box** (by Gamesaien) with fast-paced twists inspired by the **Bejeweled** series.

> **Status:** Proof of concept (Not yet released for beta or public testing).  
> *This project marks the milestone of my second month into game development. Please give feedbacks, at my [email](mailto:anhkhuongdoan754@gmail.com)

---

## Overview

*Gem Box Blitz* takes the classic box-summing mechanic of *Fruit Box* and infuses it with the vibrant visual and auditory atmosphere of tile-matching classics like *Bejeweled*. 

### Planned Modes
- **Classic Mode:** Time bombs, move count bombs or locks (like in Chuzzle?)
- **Roguelike Mode:** Money, rings, bracelets, builds, endless possibilities

---

## Tech Stack & Engine

- **Engine:** [Godot Engine](https://godotengine.org/)
- **Current Platform:** Windows
